# GIO BTC BOT\nPanel de señales BTC/USDT basado en velas de 15 minutos, RSI, MACD y EMA 20/50/200. No ejecuta operaciones.\n\n## Railway\nConecta este repositorio a Railway. Configura VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY y VAPID_EMAIL para activar push. Mantén una sola réplica. Las suscripciones se guardan en memoria y se pierden al reiniciar; antes de uso continuo se necesita almacenamiento persistente.\n\n## iPhone\nAbre el sitio en Safari > Compartir > Añadir a pantalla de inicio. Abre desde el icono y pulsa Activar notificaciones. Requiere iOS 16.4+.\n\nLas señales son reglas técnicas experimentales, no predicciones ni garantías. Verifica los resultados.\n
